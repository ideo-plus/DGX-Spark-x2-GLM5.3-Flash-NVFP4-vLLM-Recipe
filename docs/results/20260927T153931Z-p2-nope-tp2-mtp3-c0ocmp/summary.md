- 値の意味: `ttft_s` = 最初のトークンまでの時間 (秒)、`decode_tps` = 生成速度 (トークン/秒、最初のトークンまでの時間を含めない)、`prefill_tps` = 入力の処理速度 (トークン/秒)、`round_total_tps` = 1 回ぶんの合計の生成速度 (トークン/秒)。集計に入れたのは、成功した、慣らしでない試行だけである。
