# K2 第 3 段: FP8 にしていた層を NVFP4A16 にした重み（`k2s3`）

日付は 2026-09-28 JST。[ADR 0007](../decisions/0007-k2-stage2.md) の続きで、`k2s2b` の FP8 の層（489 モジュール）を NVFP4A16（重みだけ NVFP4）にした。目的は、コード・英語の decode を基準の 45 tok/s に届かせることである（`PLAN.md` §3）。
2 つの上限（GPU 1800 MHz、X925 3.0 GHz）は両台で効いていた。実機操作は対話側が行った。

## 要約

- **探り（出力 128 トークン、MTP の N = 3）:**
  - コード・英語は 42.4 → **48.0 tok/s**（`k2s2b` から +13%）。
  - ほかの 3 条件も 7〜10% 速くなった。
- **確認の段（出力 256 トークン、N = 3）:**
  - コード・英語は 37.8 → **42.1 tok/s**。**基準の 45 tok/s には約 7% 届かない。**
  - 散文・日本語は 39.7 tok/s（基準 30 を満たす）。
- 受理長はほぼ変わらない（探りで 2.97〜3.68、確認で 2.83〜3.14）。NVFP4 にしても、下書きの当たり方は落ちていない。
- 壊れは見つからなかった。
  - 確認の段の toolcall は 9 / 10。投機なしの基準の回は 7 / 10 で、入れ替わった 2 問は、どちらも「不正解 → 正解」だった。
  - humaneval+（上限 2048）は 10 / 10。needle 8k・32k は正解。印は 0 件。
- MTP の N = 4 は、確認の段で N = 3 より遅かった（code/en は 37.8 tok/s）。既定は N = 3 のままとする。

## 作った重み

| 項目 | 値 |
|---|---|
| 重み | `k2s3`。道具 `experiments/k2-quant`（commit `90b8a71`）の `--preset k2s3` |
| 形式 | NVFP4A16。E2M1 の 4 bit を 2 つずつ詰め、16 要素ごとの FP8 E4M3 のスケールと、テンソルごとの FP32 の全体スケールを持つ。まとめた層の組は全体スケールをそろえた |
| 変換 | 2 台それぞれ、約 10 分。2 台の道具のマニフェストはバイト単位で一致した。19 ファイル、186,444,563,117 バイト |
| 照合 | `serve verify` で 2 台とも合った |
| 重ね合わせ | `k2s2b`（PR #81） |
| 起動 | 両台で重みのファイルのページキャッシュを捨て（root 不要、PR #90）、`--load-format instanttensor` で起動 |

変換の前に、道具の形式の解釈を、元の重みの本物の NVFP4 の専門家（層 10、専門家 5、`down_proj`）で確かめた。戻して詰め直すと、次のとおりだった。
- 全体スケール（26496）とブロックのスケールは、本物と一致した。
- 戻した値も一致した。
- 詰めたバイト列は 6.6% が違った。値 0 の符号の付け方の違いで、戻した値は同じである。

## 確認の段の concurrency と quality（N = 3）

要約は [concurrency](20260927T154438Z-p2-nope-tp2-mtp3-08qn1m/summary.md)・[quality](20260927T154604Z-p2-nope-tp2-mtp3-wbgfn1/summary.md)。値は中央値。

| 同時の本数 | `k2s2b` の 1 本あたり | `k2s3` の 1 本あたり | `k2s2b` の合計 | `k2s3` の合計 |
|---|---:|---:|---:|---:|
| 1 | 34.970 | 38.018 | 35.245 | 38.318 |
| 2 | 24.317 | 25.777 | 41.084 | 43.913 |
| 4 | 14.423 | 12.499 | 46.498 | 41.364 |

4 本では、`k2s3` のほうが遅かった。本数が増えると、4 bit から戻す計算の負担が効くためと見る【推測】。

| 条件 | `k2s3` |
|---|---:|
| `quality/toolcall` | 9 / 10 |
| `quality/code/humaneval+`（上限 2048） | 10 / 10 |
| `quality/needle/8k/d50`、`32k/d50` | 2 / 2 |
