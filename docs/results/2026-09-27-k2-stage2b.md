# K2 第 2b 段: KDA のまとめた層まで FP8 にした重み（`k2s2b`）

日付は 2026-09-27 JST。[ADR 0007](../decisions/0007-k2-stage2.md) の第 2b 段である。派生の重み `k2s2b` を作り、vLLM の修正（重ね合わせ `k2s2b`、PR #81）を bind mount で重ねて起動した。探り（投機なし）と確認（MTP の N = 3）で、速さと壊れを見た。
2 つの上限（GPU 1800 MHz、X925 3.0 GHz）は、どの回も両台で効いていた。実機操作は対話側が行った。

## 要約

- **確認の段（出力 256 トークン、N = 3）で、4 条件とも 35.7〜37.8 tok/s になった。**
  - 元の重みより 30〜41% 速い。
  - 第 2a 段（`k2s2a`）より 11〜12% 速い。
  - 散文・日本語は 36.0 tok/s で、成功の基準（30 tok/s 以上）を超えた。
- **投機なしの探り（出力 128 トークン）では、20.4〜23.6 tok/s になった。** 元の重みの 13.9〜14.1 tok/s より 45〜67% 速い。
- 受理長は、ほぼ変わらない（2.88〜3.15）。速くなった分は、1 ステップが短くなったことによる。
- 同時 2 本の 1 本あたりは 24.3 tok/s（元の重み 20.2）で、基準（30 tok/s）にはまだ届かない。
- **壊れは見つからなかった。**
  - toolcall は、探りの 5 問・確認の 10 問とも、正解・不正解が投機なしの基準の回と同じだった。
  - humaneval+（確認の段、10 問、上限 2048）は 10/10。
  - needle（8k・32k）は正解。
  - `repetition_loop` と `replacement_char` の印は 0 件。
- KDA のまとめた層の、複製の分割（f_a・g_a）の FP8 のスケールは、既存の読み込みの処理（複製の分割を rank 0 から読む）で読めた。起動と応答に異常はなかった。

## N の探り直し（`k2s2b`、`instanttensor`、出力 128 トークン、2026-09-27 17:57〜19:38 JST）

起動の前に、両台で重みのファイルのページキャッシュを捨て（root 不要。PR #90）、`--load-format instanttensor` で起動した。bench の対象名は、どの N も `p2-nope-tp2-mtp3` を使った（宛先・モデルは同じ）。要約は [N = 2](20260927T102618Z-p2-nope-tp2-mtp3-0v7vci/summary.md)・[N = 3](20260927T085717Z-p2-nope-tp2-mtp3-uk6x8w/summary.md)・[N = 4](20260927T103453Z-p2-nope-tp2-mtp3-mkezsd/summary.md)。

| N | code/en | code/ja | prose/en | prose/ja | 受理長（code/en） |
|---|---:|---:|---:|---:|---:|
| 2 | 39.384 | 37.952 | 37.614 | 34.993 | 2.87 |
| 3 | 42.449 | 37.731 | 39.620 | 34.800 | 3.69 |
| 4 | 42.409 | 33.211 | 38.268 | 31.798 | 4.23 |

- 既定は N = 3 のままとする。4 条件で最も速く、N = 4 は日本語で落ちる。
- コード・英語は、MTP の N を変えても約 42 tok/s で頭打ちになる。下書きを増やすと受理長は伸びるが、1 ステップも同じだけ長くなる。60 tok/s には、1 ステップを縮めるか、受理長を大きく伸ばす手（深いドラフター）が要る。
- `instanttensor` での起動は、開始から ready まで約 4〜5 分だった（mmap では約 13 分）。

## 熱

GPU の最高は 59℃、熱区域の最高は 65.9℃（head）。`serve watch` の `events` は空だった。

## 次に確かめること

1. `k2s2b` の記録の段（`quick` の quality と agent）。第 2a 段と同じく、元の重みと比べる。
2. 60 tok/s（コード・英語）までの残り: MTP の N = 3 で 37.8 tok/s。1 ステップの内訳を取り直し、残りの BF16 と MoE の割合を見て、次の手（NVFP4 化、深いドラフター K3）を決める。
3. 起動の時間（mmap で約 13 分）: 変換・照合の直後でも `instanttensor` で起動できるようにする。
