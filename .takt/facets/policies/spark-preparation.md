# Spark の準備作業の境界

この作業は Mac 上のコード・構成・試験・文書の準備だけを行う。
計画・実装・レビュー・修正の全段階で、AGENTS.md と CLAUDE.md の現在の開発手順および試験方針を守る。

- SSH、rsync、Docker、実機向けの serve、重み取得、Spark への接続を実行しない。手順書にコマンドを書くことは許可する。
- 試験は偽の実行役とローカルの一時ファイルで行う。実機未検証をローカル試験で合格したとは扱わない。
- 安全条件・根拠付き argv・SHA-256・手順の文字列固定は意図した契約である。一般的な testing-lite の指針を理由に削除しない。
- cli.repo_facts の ("unknown", True) は意図した不明状態の表現であり、一般的なフォールバック禁止の対象にしない。
- 生ログ、要求・応答の本文、認証情報、exl3-tp2 の中身を調べたり記録したりしない。
- commit、push、マージ、外部への投稿は行わない。cc-sdd のスキルも使わない。
- 実機操作や承認が必要なら、その理由と未確認事項を報告し、実行せずに終了する。
